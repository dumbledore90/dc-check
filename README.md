# DC現調チェック

2MW・3MW専用コンテナ型データセンターの現地調査を、スマホで記入・撮影して、Excelと写真ZIPに書き出すツールです。

- ツール：`https://<ユーザー名>.github.io/<リポジトリ名>/`
- 手順書：`https://<ユーザー名>.github.io/<リポジトリ名>/manual.html`（ツール右上の「?」からも開けます）

## ファイル構成

| ファイル | 中身 |
| --- | --- |
| `index.html` | ツール本体。Excel作成部品（ExcelJS 4.4.0、MITライセンス）を中に埋め込んでいるので、この1ファイルで動きます |
| `manual.html` | 使う人向けの手順書。画像は中に埋め込み済み |
| `README.md` | このファイル（管理者向けメモ） |

## データの扱い

- 調査の記録と写真は、**各自のスマホのブラウザ内にだけ保存されます**。GitHubやほかのサーバーには送られません。
- このリポジトリは公開なので、**実案件の情報（地図・写真・案件番号など）は置かないでください**。手順書の画面はすべて架空のサンプルです。

## 更新のしかた

1. 直した `index.html` または `manual.html` を用意する（ファイル名は変えない）
2. リポジトリのトップで「Add file」→「Upload files」→ ドラッグ →「Commit changes」
3. 1〜2分で公開ページに反映されます。スマホで古い画面が出るときは再読み込み

## 公開設定

Settings → Pages → Source「Deploy from a branch」、Branch「main」「/ (root)」。

## 既知の制限

- ホーム画面のアイコンから開くときは電波が必要です（開いたあとは圏外でも記入・出力できます）。
- 写真は長辺1600pxに縮小して保存されます。
- iPhoneはSafariで開いて「ホーム画面に追加」して使ってください。ファイルアプリやLINEのプレビュー表示では保存できません。
